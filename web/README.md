# Interveen website

Next.js App Router site for the Interveen landing page and legal documents.

```bash
npm install
npm run dev
```

| Path | Page |
| --- | --- |
| `/` | Landing |
| `/privacy` | Privacy Policy |
| `/terms` | Terms and Conditions |
| `/support` | Support |

Colors match the native apps: charcoal `#0F172A`, surface `#1E293B`, type `#F8FAFC`, accent `#10B981`.

Canonical URL: `https://interveen.soltoapps.top`. Contact: `info@soltoapps.top`.
